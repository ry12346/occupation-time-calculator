# 占領時間・到着予想時刻計算

更新版: `2026.08.07-1`

開始日時と占領するマス数から、占領終了予想日時を計算する静的Webページです。

## 計算ルール

- 0:00〜2:00: 1マス10分
- 2:00〜6:00: 1マス30分
- 6:00〜7:00: 1マス10分
- 7:00〜24:00: 1マス5分
- マス間の移動: 15秒
- 最後のマスの後には移動時間を加算しません
- 各マスの所要時間は、そのマスの占領開始時刻を基準に決定します

## 主な機能

- 占領終了予想日時の表示
- 総所要時間、占領時間、移動時間の表示
- 0:00〜2:00の10分帯、2:00〜6:00の30分帯、6:00〜7:00の10分帯へ初めて入るマス番号の表示
- 時間帯別のマス数と所要時間の内訳
- 時間帯が切り替わるマスの一覧
- 結果のクリップボードコピー
- スマートフォン対応
- 外部ライブラリ・サーバー不要
- 座標を1地点ずつ貼り付けて、斜め移動を考慮した推定マス数を自動算出
- 座標を追加・削除するたびに推定マス数を「占領するマス数」へ自動反映
- マス数欄は常に手動編集可能
- 貼り付け時に1座標ずつ確定するため、`642,1671636,1661` のような連結を防止


## 座標からマス数を算出

ゲーム上でコピーした座標を「次の座標を貼り付け」欄へ1地点ずつ貼り付けます。貼り付けイベントごとに1地点として登録されるため、改行を手で入れる必要はありません。

例:

```text
930,1708
917,1739
878,1712
822,1684
799,1664
```

斜め移動が可能として、各区間は次の式で推定します。

```text
区間マス数 = max(|X2 - X1|, |Y2 - Y1|)
```

各区間を合計した推定マス数を、占領するマス数欄へ自動反映します。スタート地点そのものはマス数に含めません。必要に応じて、反映後のマス数は手動で自由に修正できます。

座標は個別に削除でき、削除後も経路を再計算します。「座標をクリア」では座標リストのみ消去し、手動入力したマス数は維持します。
