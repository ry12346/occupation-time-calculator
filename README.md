# 占領時間・到着予想時刻計算

開始日時と占領するマス数から、時間帯ごとの占領時間とマス間の移動時間を考慮して、占領終了予想日時を計算するWebページです。

## 使い方

1. 「現在時刻を設定」を押すか、「占領開始日時」を指定します。
2. 「占領するマス数」を入力します。
3. 入力内容に合わせて、終了予想日時・総所要時間・時間帯ごとの内訳が自動で更新されます。

マス数は手動で自由に入力できます。座標から推定した値を使ったあとでも、山や川などによる迂回を考慮して手動で修正できます。

## 座標からマス数を算出する

ゲーム上でコピーした座標を「次の座標を貼り付け」欄へ、進む順番に1地点ずつ貼り付けます。

例:

```text
930,1708
917,1739
878,1712
822,1684
799,1664
```

1地点を貼り付けるたびに自動で座標リストへ追加されます。2地点目以降が追加されると、斜め移動可能として各区間のマス数を求め、合計を「占領するマス数」へ自動反映します。

スタート地点そのものはマス数に含めません。登録した座標は個別に削除でき、削除すると残っている経路でマス数を再計算します。「座標をクリア」を押すと座標リストだけを消去し、マス数欄の値は残ります。

## 計算ルール

- 0:00〜2:00: 1マス10分
- 2:00〜6:00: 1マス30分
- 6:00〜7:00: 1マス10分
- 7:00〜24:00: 1マス5分
- マス間の移動: 15秒
- 最後のマスの後には移動時間を加算しません
- 各マスの所要時間は、そのマスの占領開始時刻を基準に決定します

## 表示される内容

- 占領終了予想日時
- 総所要時間
- 占領に使う時間とマス間移動に使う時間
- 時間帯ごとのマス数と所要時間
- 10分・30分の時間帯へ入る最初のマス番号
- 時間帯が切り替わるマスの一覧

## 座標計算について

座標から求めるマス数は、斜め移動が可能であることを前提にした推定値です。山・川などの占領不可マスや、ゲーム内部の通行制限は自動判定しません。実際の経路が長くなる場合は、マス数欄を手動で修正してください。
